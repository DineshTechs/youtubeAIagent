# V1.7.0 + handover fixes (2026-11-15)

Applied on top of the V1.7.0 Audio Intelligence release (`yta-v170-full.zip`).
No database migration, no new dependencies, no Docker/Redis. Rendering, OCR,
image generation and narration are unchanged.

## Fixes
1. **Approval gate** (`server/src/utils/approvalGate.js`, `videoController.js`):
   approval now always requires a passing technical QA report AND all three
   visual-review checks, for every QA version. Previously any QA version other
   than 1.2–1.5.0 skipped these checks.
   Note: an old video with no QA report must have "Run QA again" before approval.
2. **Export redaction** (`client/src/redact.js`, `App.jsx`): secrets inside log
   text and error messages (API keys, Bearer tokens, `?key=` URLs, MongoDB URIs,
   URL passwords, cookies, known provider key formats) are masked in every copy
   and download, not only secret-named fields. Download names keep Hindi titles.
   Files are saved as UTF-8.
3. **Pipeline trace** (`server/src/utils/traceSafe.js`): large stage data is kept
   as a readable truncated preview instead of `"[object Object]"`.
4. **Worker reliability** (`server/src/workers/recovery.js`, `worker.js`): a
   MongoDB error during job polling is logged instead of crashing Node. A running
   job sends a heartbeat every 15 s; a RUNNING job with no heartbeat for 2 minutes
   (crash/restart) is marked FAILED (saved assets kept) so Continue works. The
   check runs at startup and every minute. A job owned by another live backend
   process is never touched. `app.js` now binds port 4000 before starting the
   worker, so a second `npm run dev` exits ("port already in use") instead of
   interfering with a running job.
5. **Audio intelligence** (`audioIntelligence.js`, `qualityAssurance.js`):
   - Peak/RMS come from FFmpeg's Overall block (was channel 1 only).
   - One FFmpeg pass (silence at -45 dBFS, 0.65 s minimum) feeds Opening audio
     start, Audio silence scan and Audio intelligence, so numbers always agree.
     Opening/whole-file rules are unchanged (0.75 s / 1 s minimum as before).
   - Each gap has position (opening/middle/ending), scene-join context, severity
     and a plain-language review reason. Pauses are not treated as defects.
   - Audio intelligence only WARNs for near-clipping or a fully silent track, so
     one pause no longer produces three warnings.
   - No audio stream: audio checks show SKIPPED instead of a raw FFmpeg log.
   - Silence is never removed or edited automatically.
6. **Dashboard** (`App.jsx`, `styles.css`): the existing Video QA Report shows
   peak, RMS and each gap with its reason under "Audio intelligence"; QA .txt
   export includes the same lines. Layout, navigation and Copy & Export Center
   are otherwise unchanged; `App` remains the default export.

## Verify locally (PowerShell, project root)
```
npm install
npm test --workspace server
npm test --workspace client
npm run build --workspace client
npm run dev
```
Then open a video → Video Details → "Run QA again" to produce a V1.7.0 report.

# YouTube AI Agent V1.6.2 — Image Text Leakage Hotfix

This is a SERVER-ONLY update based on the uploaded `server(2).zip` (package version 1.6.2).
The upload did not include the React/client application, so no frontend files are included.

## Changes
- OCR now always uses English + Hindi traineddata for generated artwork.
- OCR classifies even a single readable word or digit as unwanted text in the image layer.
- Short Hindi and other supported non-Latin script detections are also flagged.
- Real generated images must pass OCR before approval; OCR initialization/inspection errors now fail the image stage instead of silently accepting uninspected artwork.
- Previously saved images that cannot pass OCR are no longer reused.
- Strengthened prompt and retry instructions against pseudo-writing, scribbles, fake glyphs and text-like strokes.
- Added unit tests for one-word text, digits and non-Latin script detection.

## Install
1. Stop the backend.
2. Back up your current `server` folder.
3. Extract this update over your existing project root, preserving `server/.env` and your data/storage directories.
4. Run from project root:
   `npm install --workspace server`
   `npm test --workspace server`
5. Restart backend.

The uploaded server archive already contained `eng.traineddata` and `hin.traineddata`; OCR is configured to load both from the server directory.

## Important limitations
OCR is not a perfect logo detector and cannot guarantee detection of every stylized logo, tiny text, or abstract pseudo-glyph. Prompt safeguards remain necessary. A strict OCR false positive can cause a scene to fail after two regeneration retries; inspect its OCR text/confidence in the job logs.

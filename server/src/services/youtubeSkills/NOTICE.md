YouTube Agent Skill integration
================================

Integrated into this application from:
https://github.com/Jakeschincariol/youtube-agent-skill

Upstream project: Copyright (c) 2026 Jake Schincariol
License: MIT

This integration adapts the project's hook scoring, title/thumbnail linting,
transcript editing, chapters, retention and channel-relative viral analysis
for the application's Node.js API and UI. The AI-oriented skills are exposed
through the application's active AI provider.

Upstream skills:
yt-script, yt-package, yt-edit, yt-comment, yt-plan, yt-viral,
yt-retention, yt-shorts, yt-seo, yt-chapters, yt-audit.

The upstream pack does not publish videos automatically. This integration
also does not add automatic publishing.
